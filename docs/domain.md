# 机器人场景验收场领域约定

服务采用事件时间与接收时间分离的记录方式：所有记录携带调用方提供的 `occurredAt`（事件时间）与服务端写入的 `receivedAt`（接收时间）。所有业务身份由调用方提供的稳定标识表示，审计记录不得以覆盖方式修改——服务只追加记录，不提供任何删除或局部修改入口（DELETE/PATCH 一律 405）。

## 已落地的业务能力

- **场景验收项目**：项目是测试与争议处理的独立组织单元；成员角色为 buyer / supplier / lab / observer，观察员只读且权限严格按项目隔离（非成员一律 404）。
- **基线封存**：买方提交场地约束与成功判据并封存，封存时计算内容哈希，封存后不可修改；未封存基线不得开跑。
- **设备登记**：供应商登记机器人及固件版本，每个固件版本绑定设备密钥，用于证据签名校验。
- **脚本登记**：测试脚本按内容哈希寻址，内容变化即新版本。
- **轮次**：测试运行按（机器人、固件版本、脚本哈希）归入轮次；设备或脚本变化自动生成新轮次，旧轮次标记为被取代。
- **证据上传**：步骤与传感结果带签名、按事件标识幂等、按分段内序号续传；服务恢复后客户端凭 `upload-status` 从中断处继续上传，重传已接收事件安全幂等。
- **中断与重试**：运行可中断，并从已到达的安全检查点重试；重试开启新分段，检查点之后的事件被整体标记为"被取代"但原样保留，不允许挑选性删除失败。
- **资源调度**：实验室按时段预约资源，同一资源时段重叠即冲突（409），取消预约以追加记录方式生效。
- **报告与复算**：报告由有效事件链确定性计算，每条结论携带证据标识与规则标识；失败归因区分环境故障、操作偏差与产品表现；买方可生成报告快照，任何成员可随时复算并逐条比对结论变化。
- **争议处理**：项目内角色可对运行或结论发起争议，买方组织结案；未结争议会出现在报告中。

## 安全说明

- 证据签名采用 HMAC-SHA256（设备密钥随固件登记）。生产环境应替换为非对称签名（如 Ed25519），设备持私钥、服务存公钥。
- 身份令牌与设备密钥仅用于受控运行环境，审计与查询输出一律脱敏。

# 机器人场景验收场领域约定

服务采用事件时间与接收时间分离的记录方式。所有业务身份由调用方提供的稳定标识表示，审计记录不得以覆盖方式修改。

## 核心概念

- **验收项目**：买方与供应商协作的独立边界，权限按项目隔离。
- **判据封存**：场地约束与成功判据一经封存不可修改，版本化并带内容哈希；重新封存产生新版本。
- **轮次**：以「机器人固件 + 脚本版本 + 判据版本」的配置指纹划分，任何变化自动开启新轮次，历史轮次保留。
- **测试运行与尝试**：运行由一次或多次尝试组成；中断后只能从已通过的安全检查点开启新尝试，失败记录永久保留。
- **签名记录**：步骤结果与传感数据携带 HMAC 签名与事件时间，入库时记录接收时间；按 recordId 幂等去重以支持断点续传。
- **失败归因**：失败记录必须归类为环境故障、操作偏差或产品表现，报告按三类分别汇总。
- **报告**：事件日志的纯函数，结论附证据记录编号，发布后可复算比对内容哈希。
- **争议**：针对记录或结论的异议，由买方管理员处理结案，全程仅追加留痕。

## 不变量

1. 事件日志仅追加，任何状态变化先落盘再应用，重启后重放恢复。
2. 业务身份（项目、机器人、脚本、运行、记录、争议）由调用方提供稳定标识。
3. 同一实验室资源的预约时段不得重叠；运行中的资源不被其他运行占用。
4. 观察员仅对其被授权的项目拥有只读权限。
